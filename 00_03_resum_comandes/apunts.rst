| Comanda        | Descripció                                                                                  |
| ------------------ | --------------------------------------------------------------------------------------- |
| `$ mkdir carpeta/` | crea una carpeta anomenada `carpeta/`                                                   |
| `$ cd carpeta/`    | canvia el directori actual a `carpeta/`                                                 |
| `$ cat fitxer`     | mostra el contingut del fitxer a la terminal                                            |
| `$ gedit fitxer &` | obre el fitxer amb l’editor de text gedit en segon pla                                  |
| `$ ls`             | mostra els fitxers i carpetes del directori actual                                      |
| `$ rm fitxer`      | esborra el fitxer indicat                                                               |
| `$ git init`       | permet inicialitzar un repositori git                                                   |
| `$ git clone`      | clona un repositori                                                                     |
| `$ git status`     | mostra l’estat dels fitxers del repositori                                              |
| `$ git add`        | afegeix fitxers a l’índex                                                               |
| `$ git commit`     | desa els canvis afegits a l’índex en el repositori local amb un missatge                |
| `$ git push`       | envia els canvis del repositori local al remot (GitHub)                                 |
| `$ git pull`       | descarrega i integra els canvis del repositori remot (github) al local                  |
